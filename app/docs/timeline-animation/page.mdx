## Component API

### TimelineAnimation

The line fills up to the middle of the scrolling area, and each dot takes the primary colour when the line reaches it. Entries rise 8px and fade in over 300ms the first time they enter the view, then stay. With reduced motion, the line is full and every entry is in place from the start.

| Prop         | Type                             | Default   | Description                                                                     |
| :----------- | :------------------------------- | :-------- | :------------------------------------------------------------------------------ |
| children     | React.ReactNode                  |           | The `TimelineAnimationItem` elements, in reading order.                         |
| containerRef | RefObject\<HTMLElement \| null\> |           | The scrolling element, when it is not the page. It needs a non-static position. |
| className    | string                           | undefined | Optional CSS class for the list.                                                |

### TimelineAnimationItem

| Prop      | Type            | Default   | Description                                                                             |
| :-------- | :-------------- | :-------- | :-------------------------------------------------------------------------------------- |
| children  | React.ReactNode |           | The content of the entry. Its first line sits next to the dot.                          |
| className | string          | undefined | Classes of the entry, merged over `relative ps-8 pb-10`. The bottom padding is the gap. |
