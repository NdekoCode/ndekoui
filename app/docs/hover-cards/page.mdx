## Component API

### HoverEffectCard

Renders an `<a>`: every other anchor attribute (`href`, `target`, `rel`) passes through.

| Prop        | Type                                  | Default | Description                                                         |
| :---------- | :------------------------------------ | :------ | :------------------------------------------------------------------ |
| effect      | 'zoom' \| 'rise' \| 'tilt' \| 'trace' |         | The hover treatment.                                                |
| title       | React.ReactNode                       |         | The card title.                                                     |
| description | React.ReactNode                       |         | A short line under the title.                                       |
| meta        | React.ReactNode                       |         | A small row of details. With `rise`, it is the panel that rises in. |
| image       | `{ src: string; alt: string }`        |         | The card image.                                                     |
| className   | string                                |         | Classes for the link.                                               |

## Accessibility and motion

- Every card is a link with a visible focus outline. Keyboard focus also brings up the rising details and the traced border.
- Hover effects run only on devices that can hover. The tilt follows a mouse, never a finger.
- With reduced motion, the zoom and the tilt are off, the rising details only fade and the border appears without drawing.
