## Component API

### Marquee

| Prop         | Type                       | Default      | Description                                                                                          |
| :----------- | :------------------------- | :----------- | :--------------------------------------------------------------------------------------------------- |
| children     | React.ReactNode            |              | The items of one loop.                                                                               |
| direction    | 'horizontal' \| 'vertical' | 'horizontal' | The axis of the loop. A vertical marquee needs a height.                                             |
| reverse      | boolean                    | false        | Runs the loop the other way.                                                                         |
| pauseOnHover | boolean                    | true         | Pauses under the pointer and while an item inside has focus.                                         |
| gap          | number                     | 16           | The space between items, in pixels.                                                                  |
| duration     | number                     |              | Seconds for one loop. Without it, the theme default applies: 40 seconds across, 60 down.             |
| repeat       | number                     | 2            | Copies of the items in each half of the loop. Raise it when one copy is narrower than the container. |
| fade         | boolean                    | true         | Fades the items out at both edges.                                                                   |
| className    | string                     |              | Optional CSS class for the container.                                                                |

Only the first copy is read by screen readers and reached with the keyboard; the copies are hidden from both. Under reduced motion the loop stops: a horizontal marquee shows one copy, wrapped and centred, and a vertical one shows its first items.

Marquees are ambient motion: keep them on marketing pages, never inside the application.

### Compared with Infinite Slider

Infinite Slider moves its row from JavaScript, measures it, and can slow down smoothly under the pointer with `speedOnHover`. Marquee hands the loop to the browser, so it stays smooth when the page is busy, and it pauses under the pointer. Prefer Marquee for a constant loop and Infinite Slider when the speed has to change.
