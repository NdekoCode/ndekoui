## Component API

### SmoothScroll

Only the mouse wheel is eased. The page keeps its real scroll position at every frame, so sticky elements, scroll-linked animations, anchors, the keyboard, the scrollbar, touch and screen readers behave as they do without it. When something else moves the page, the easing stops and starts again from there. With reduced motion, nothing is attached at all.

The wheel stays native when it is pinched to zoom, sideways or held with Shift, inside an inner area that can still scroll that way, inside an element marked `data-smooth-scroll-ignore`, and while the page is locked by a dialog.

Use `root` on a marketing page to ease the window; without it, the wrapper is the scrolling area and needs a height.

| Prop      | Type            | Default   | Description                                                                              |
| :-------- | :-------------- | :-------- | :--------------------------------------------------------------------------------------- |
| children  | React.ReactNode |           | The content.                                                                             |
| root      | boolean         | false     | Eases the scrolling of the window instead of the wrapper.                                |
| lerp      | number          | 0.12      | The share of the remaining distance covered in each frame at 60 fps, between 0.01 and 1. |
| enabled   | boolean         | true      | Turns the easing on or off without unmounting.                                           |
| className | string          | undefined | Classes of the wrapper, merged over `relative overflow-y-auto` when it scrolls itself.   |

### useSmoothScroll

The same behaviour as a hook, for a scrolling element you already have.

| Option    | Type                             | Default | Description                                         |
| :-------- | :------------------------------- | :------ | :-------------------------------------------------- |
| container | RefObject\<HTMLElement \| null\> |         | The scrolling element. Leave it out for the window. |
| lerp      | number                           | 0.12    | As above.                                           |
| enabled   | boolean                          | true    | As above.                                           |
