## Component API

### StackingCards

Each card gets a pinned frame as tall as the scrolling area. The deepest card ends at 90% of its size and the one on top stays at full size; the scale and the fade follow the scroll position directly, without re-rendering. With reduced motion, the cards are a plain list at full size.

| Prop           | Type                             | Default   | Description                                                                     |
| :------------- | :------------------------------- | :-------- | :------------------------------------------------------------------------------ |
| children       | React.ReactNode                  |           | The `StackingCard` elements.                                                    |
| containerRef   | RefObject\<HTMLElement \| null\> |           | The scrolling element, when it is not the page. It needs a non-static position. |
| frameClassName | string                           | `h-svh`   | Classes of each pinned frame. Its height should match the scrolling area.       |
| peek           | number                           | 16        | How many pixels of each card stay visible above the next one.                   |
| className      | string                           | undefined | Optional CSS class for the stack.                                               |

### StackingCard

| Prop      | Type            | Default   | Description                                                                    |
| :-------- | :-------------- | :-------- | :----------------------------------------------------------------------------- |
| children  | React.ReactNode |           | The content of the card. Give every card the same height so the edges line up. |
| className | string          | undefined | Classes of the card surface: background, ring, radius and width.               |
