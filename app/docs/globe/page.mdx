# Globe

A dotted globe drawn with [cobe](https://github.com/shuding/cobe), coloured from the theme tokens. It turns slowly on its own, follows a drag and keeps its momentum when released, and can glide to a location you pass in.

## Examples

### Cities and routes

Markers in the primary colour, with arcs between some of them. Drag the globe, or focus it and use the arrow keys.

## Component API

### Globe

Renders a square that fills the width of its container, up to 600px. The colours come from `--background`, `--foreground`, `--card` and `--primary`, and follow the theme when it changes.

| Prop         | Type                     | Default | Description                                                                         |
| :----------- | :----------------------- | :------ | :---------------------------------------------------------------------------------- |
| markers      | GlobeMarker[]            | []      | Points in the primary colour. `{ location: [latitude, longitude], size?, label? }`. |
| arcs         | GlobeArc[]               | []      | Curved routes between two locations. `{ from: [lat, lng], to: [lat, lng] }`.        |
| focus        | [number, number] \| null | null    | A location to glide to and hold. `null` lets the globe turn on its own again.       |
| autoRotate   | boolean                  | true    | Whether the globe turns on its own when nobody holds it.                            |
| turnDuration | number                   | 40      | Seconds for one full turn on its own.                                               |
| tilt         | number                   | 15      | The starting tilt in degrees, positive to show more of the northern hemisphere.     |
| markerSize   | number                   | 0.05    | The size of markers that do not set their own, relative to the globe.               |
| label        | string                   | 'Globe' | The accessible name of the globe.                                                   |
| className    | string                   |         | Classes for the square wrapper, for example a `max-w-*`.                            |

## Accessibility and motion

- The globe is a focusable group. The left and right arrow keys turn it, the up and down arrow keys tilt it. Marker labels are listed for screen readers.
- On touch screens a horizontal drag turns the globe and a vertical one scrolls the page.
- The globe draws frames only while it is on screen, and stops drawing once it has settled when it is not turning on its own.
- With reduced motion it does not turn on its own, a release does not keep spinning, and `focus` jumps straight to the location. Dragging still works.
- The atmosphere around the sphere is tinted with the page colour, so there is no glow.
