# Image Tabs

Tabs that change an image in place while the indicator travels to the chosen tab.

## Examples

### Tabs with text and image

The frame crossfades: the new image fades in over the previous one, so nothing slides and no background shows through.

## Component API

### ImageTabs

| Prop            | Type                         | Default      | Description                                                        |
| :-------------- | :--------------------------- | :----------- | :----------------------------------------------------------------- |
| `children`      | `ReactNode`                  |              | The list and the frame.                                            |
| `defaultValue`  | `string`                     |              | The tab selected first.                                            |
| `value`         | `string`                     |              | The selected tab, when controlled.                                 |
| `onValueChange` | `(value: string) => void`    |              | Called when another tab is chosen.                                 |
| `orientation`   | `'vertical' \| 'horizontal'` | `'vertical'` | Arrow keys follow it, and the clip wipes along it.                 |
| `className`     | `string`                     |              | Classes of the root, a grid with a gap by default, for the layout. |

### ImageTabsList

| Prop              | Type                     | Default  | Description                                                               |
| :---------------- | :----------------------- | :------- | :------------------------------------------------------------------------ |
| `variant`         | `'list' \| 'thumbnails'` | `'list'` | A list of text tabs on a travelling surface, or a strip of thumbnails.    |
| `activateOnFocus` | `boolean`                | `true`   | Arrow keys select the tab they reach. The images are mounted, so no wait. |
| `aria-label`      | `string`                 |          | The name of the tab list.                                                 |
| `className`       | `string`                 |          | Optional classes of the list.                                             |

### ImageTabsTab

| Prop         | Type        | Default | Description                                               |
| :----------- | :---------- | :------ | :-------------------------------------------------------- |
| `value`      | `string`    |         | The value shared with its panel.                          |
| `children`   | `ReactNode` |         | `ImageTabsTitle` and `ImageTabsDescription`, or an image. |
| `aria-label` | `string`    |         | Required when the tab only holds an image.                |
| `disabled`   | `boolean`   |         | Whether the tab can be chosen.                            |
| `className`  | `string`    |         | Optional classes of the tab.                              |

### ImageTabsFrame

| Prop         | Type               | Default  | Description                                                      |
| :----------- | :----------------- | :------- | :--------------------------------------------------------------- |
| `children`   | `ReactNode`        |          | One `ImageTabsImage` or `ImageTabsPanel` per tab.                |
| `transition` | `'fade' \| 'clip'` | `'fade'` | A 200ms crossfade, or a 320ms wipe. Reduced motion always fades. |
| `className`  | `string`           |          | Classes of the frame, `aspect-[3/2]` by default.                 |

### ImageTabsImage

| Prop        | Type     | Default | Description                    |
| :---------- | :------- | :------ | :----------------------------- |
| `value`     | `string` |         | The value of its tab.          |
| `src`       | `string` |         | The image source.              |
| `alt`       | `string` |         | The description of the image.  |
| `className` | `string` |         | Optional classes of the image. |

`ImageTabsPanel` takes `value`, `children` and `className` and shows any content in the frame with the same transition. `useImageTabs` returns the selected `value`, the `previousValue` and the `orientation`.
