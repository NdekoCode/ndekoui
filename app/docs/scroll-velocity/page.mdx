# Scroll Velocity

Rows that loop sideways at a calm speed and run faster while the page scrolls. All the rows of a group read one shared scroll speed, turn around when the page scrolls up and lean slightly into their speed. Scroll the page to drive the examples.

For one large line of text, [Scroll Text Marquee](/docs/scroll-text-marquee) is lighter. Scroll Velocity is for a stack of rows, with text, chips or pictures, that should move as one group.

## Component API

### ScrollVelocity

Reads the scroll speed once for every row inside it.

| Prop              | Type                             | Default | Description                                                                    |
| :---------------- | :------------------------------- | :------ | :----------------------------------------------------------------------------- |
| children          | React.ReactNode                  |         | One or more `ScrollVelocityRow`.                                               |
| containerRef      | RefObject\<HTMLElement \| null\> |         | A scrolling element to follow instead of the page.                             |
| reverseOnScrollUp | boolean                          | true    | Turns every row around while the page scrolls up, until it scrolls down again. |
| lean              | boolean                          | true    | Slants the rows into their speed, up to 6 degrees.                             |
| fade              | boolean                          | true    | Fades both ends of the rows.                                                   |
| className         | string                           |         | Classes for the group, a vertical flex column.                                 |

### ScrollVelocityRow

| Prop      | Type              | Default | Description                                                                                          |
| :-------- | :---------------- | :------ | :--------------------------------------------------------------------------------------------------- |
| children  | React.ReactNode   |         | One copy of the row's content. It is repeated as many times as the row needs to stay filled.         |
| speed     | number            | 40      | Speed at rest, in pixels per second. Scrolling at 1000 pixels per second makes it five times faster. |
| direction | 'left' \| 'right' | 'left'  | The direction at rest.                                                                               |
| gap       | number            | 32      | Space between two copies, in pixels.                                                                 |
| className | string            |         | Classes for the row, for example its text size.                                                      |

## Accessibility and motion

- The rows move through motion values only: nothing re-renders while they run.
- Rows move only while the group is on screen and the tab is visible, and a frame after a long pause never throws them forward.
- One copy of each row is read by screen readers and reached by the keyboard; the repeats are hidden from both.
- With reduced motion, the rows stand still and show their content from the start.
- Scroll pieces belong on marketing pages. A row that keeps moving needs a way to stop for people who find it distracting: reduced motion stops it here, and a page that relies on it can offer a pause control as well.
