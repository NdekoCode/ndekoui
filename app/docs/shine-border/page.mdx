# Shine Border

A slanted glint that sweeps across a card from left to right and catches its border on the way, the way light crosses a metal frame. It runs on a slow loop to draw the eye to one card, or once when a card that is a link is hovered or focused.

Where [Border Beam](/docs/border-beam) travels around the edge to say that something is running, the shine crosses the whole frame at once and then rests.

## Component API

### ShineBorder

Place it inside a card with `position: relative`. It takes the card's corner radius and draws over its hairline. With `trigger='hover'`, it listens to the card it sits in.

| Prop      | Type              | Default | Description                                                               |
| :-------- | :---------------- | :------ | :------------------------------------------------------------------------ |
| trigger   | 'loop' \| 'hover' | 'loop'  | Sweep on a loop, or once when the card is hovered or gets keyboard focus. |
| duration  | number            | 1.4     | Seconds for one sweep across the card.                                    |
| interval  | number            | 4       | Seconds of rest between two sweeps on a loop.                             |
| width     | number            | 1       | The thickness of the shining border, in px.                               |
| className | string            |         | Classes for the border layer. The colour comes from `text-primary`.       |

## Accessibility and motion

- The shine is decorative and hidden from assistive technology.
- The sweep moves with a transform, so it stays smooth while the page is busy. A hover sweep that is already running finishes before another can start.
- Use the hover trigger only on cards that can be clicked.
- With reduced motion there is no sweep: the card keeps its usual border.
