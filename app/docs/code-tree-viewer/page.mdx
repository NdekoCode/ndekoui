A file tree beside a code panel: choose a file and its code appears in place, highlighted, with its name and a copy button above it.

## Component API

### CodeTreeViewer

| Prop            | Type           | Default        | Description                                               |
| :-------------- | :------------- | :------------- | :-------------------------------------------------------- |
| files           | CodeTreeFile[] |                | The files to show. Keep the array stable between renders. |
| defaultPath     | string         | the first file | The file shown on mount.                                  |
| showLineNumbers | boolean        | true           | Whether each line starts with its number.                 |
| aria-label      | string         | 'Files'        | The name of the tree.                                     |
| className       | string         |                | Classes for the frame, such as its height.                |

### CodeTreeFile

| Field    | Type   | Description                                                              |
| :------- | :----- | :----------------------------------------------------------------------- |
| path     | string | The file path with `/` between folders, such as `src/lib/format-day.ts`. |
| code     | string | The content of the file.                                                 |
| language | string | A Shiki language id. By default it comes from the file extension.        |

## Behaviour

- Highlighting runs in the browser with Shiki, in light and dark themes at once, so the panel follows the theme without highlighting again. Every file is highlighted once when the viewer mounts, so switching files shows colours at once; until then the code shows plain, at the same size.
- The panel changes its content in place. Only the row you choose and the folder you open respond.
- The tree is a list of buttons: arrows move between rows and open folders, Enter or Space shows a file.
