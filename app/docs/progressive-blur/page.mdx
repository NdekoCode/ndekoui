# Progressive blur

A Progressive Blur component creates a layered blur effect using motion and gradient masks. It progressively blurs layers based on direction and intensity, adding visual depth.

### Progressive blur over a scrolling list

`blurLevels` sets the blur of each layer in pixels. Levels that double (0.5, 1, 2, 4...) read as an even fade, since the eye judges blur by ratio rather than by pixels. Two blurs sit over the list, a short one at the top and a longer one at the bottom, and stay in place while the list scrolls.

## Component API

### ProgressiveBlur

| Prop          | Type                                   | Default  | Description                                                                                                    |
| :------------ | :------------------------------------- | :------- | :------------------------------------------------------------------------------------------------------------- |
| direction     | 'top' \| 'right' \| 'bottom' \| 'left' | 'bottom' | The edge where the blur is strongest.                                                                          |
| blurLayers    | number                                 | 8        | The number of blur layers.                                                                                     |
| className     | string                                 | ''       | The class name to apply to the component.                                                                      |
| blurIntensity | number                                 | 0.25     | Pixels of blur added by each layer: layer n blurs `n * blurIntensity`.                                         |
| blurLevels    | readonly number[]                      |          | The blur of each layer, in pixels, from the clear side to the edge. Replaces `blurLayers` and `blurIntensity`. |

The blur is decorative and hidden from assistive technology. Put it over the content with `pointer-events-none`, so clicks and scrolling reach what is under it.
