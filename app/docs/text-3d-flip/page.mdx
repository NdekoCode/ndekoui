# Text 3D Flip

Each letter is the front of a small block. When the link or button it sits in is hovered or focused from the keyboard, the blocks turn one after another and show their other face, then turn back when the pointer leaves.

## Examples

### Navigation links

The back face takes the brand ink, so the link under the pointer reads as the chosen one. Tab through the links: keyboard focus flips them too.

### Buttons

The wave can start from the middle of the label, from either end, from a letter of your choice or in a fixed shuffled order. The turn can go up, down, left or right.

### Driven by state

With `flipped`, the text turns when your state changes instead of on hover. Here a finished task turns to its muted face. A task that is already done when the list loads shows its muted face without turning.

## Component API

### Text3DFlip

| Prop          | Type                                                | Default | Description                                                                           |
| :------------ | :-------------------------------------------------- | :------ | :------------------------------------------------------------------------------------ |
| children      | string                                              |         | The text. Words still wrap between them.                                              |
| as            | React.ElementType                                   | 'span'  | The element to render.                                                                |
| className     | string                                              |         | Classes for the element.                                                              |
| textClassName | string                                              |         | Classes for the front face of every letter.                                           |
| backClassName | string                                              |         | Classes for the back face of every letter, for example another colour.                |
| direction     | 'up' \| 'down' \| 'left' \| 'right'                 | 'up'    | Which way the letters turn.                                                           |
| staggerFrom   | 'first' \| 'last' \| 'center' \| 'random' \| number | 'first' | Where the wave starts. A number starts at that letter. 'random' is a fixed shuffle.   |
| stagger       | number                                              | 0.03    | Seconds between two letters.                                                          |
| duration      | number                                              | 0.5     | Seconds for one letter to turn. Turning back takes 70% of it, with a shorter stagger. |
| flipped       | boolean                                             |         | Controls the face shown. When it is set, hover and focus are ignored.                 |

## Accessibility and motion

- The text listens to the nearest link, button, tab, menu item or label it sits in. Plain text that is not inside one does not react to the pointer, because text that moves on hover reads as something to click. Drive it with `flipped` there.
- Touch does not flip the letters, so a tap goes straight to the link.
- Screen readers hear the text once. The letter faces are hidden from them.
- The turn uses CSS transitions on `transform`, so a pointer that leaves halfway turns the letters back from where they are.
- With reduced motion, the faces cross-fade in 150ms and nothing turns.
