# Installation

ndekoui is a shadcn registry, listed in the shadcn registry directory as `@ndeko`. Every primitive, component, block and template installs with the shadcn CLI, and the pieces it uses come with it. It works with React 19 and Tailwind CSS 4.

<Steps>

<Step>Set up shadcn</Step>

Once per project. It creates the `components.json` file the CLI reads, and the `lib/utils.ts` helper.

<CodeBlock code={`npx shadcn@latest init`} lang='bash' className='h-[52px]' />

<Step>Add the theme</Step>

Tokens for light and dark, the hairline utilities, the 3D materials and the reduced-motion switch.

<CodeBlock
  code={`npx shadcn@latest add @ndeko/theme`}
  lang='bash'
  className='h-[52px]'
/>

<Step>Add a component</Step>

<InstallationCli value='text-effect' />

The command above adds the Text Effect component to `components/core`, with Motion and the helpers it uses. Icons come with the components that need them, from the `icons` item, so there is no icon package to install by hand.

You can also copy the code by hand from the component's page.

</Steps>

## The @ndeko name

The shadcn CLI finds `@ndeko` in its registry directory, so there is nothing to declare in `components.json`: the CLI adds the entry itself the first time you install an item.

With an older shadcn CLI that does not read the directory, give it the full address of the item instead:

<CodeBlock
  code={`npx shadcn@latest add https://ui.ndekocode.dev/r/text-effect.json`}
  lang='bash'
  className='h-[52px]'
/>

## Reduced motion

The theme drops movement when the system asks for reduced motion, and every ndekoui component reads the same setting before it moves. The motion library does not read the CSS rule, so wrap your app in `MotionConfig` once: any other motion animation in the app then keeps its fades and drops its movement too.

<CodeBlock
  code={`'use client';

import { MotionConfig } from 'motion/react';

export function MotionProvider({ children }: { children: React.ReactNode }) {
  return <MotionConfig reducedMotion='user'>{children}</MotionConfig>;
}`}
  lang='tsx'
/>

Then render `<MotionProvider>` around the content of your root layout. A spinner keeps turning, as people expect a loader to.

## In an AI app builder

Every preview has an Open in menu next to its Code button.

- **v0** reads the item straight from the registry.
- **Lovable, Cursor, Claude and ChatGPT** open with a prompt that holds the install command and what the project needs.
- **Bolt, Replit, Windsurf** and any other builder: copy the same prompt from the menu and paste it there.

An item brings everything it uses: the theme, the icons, the primitives, its sample pictures in `public/`, and the parts it imports. Nothing points back to this site. The project needs React 19 and Tailwind CSS 4. No component depends on Next.js, so they also run in Vite projects.
