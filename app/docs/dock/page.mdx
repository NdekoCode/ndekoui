## Component API

### Dock

| Prop                 | Type          | Default                                      | Description                                                                              |
| :------------------- | :------------ | :------------------------------------------- | :--------------------------------------------------------------------------------------- |
| children             | ReactNode     |                                              | The child elements to be animated.                                                       |
| className            | string        | undefined                                    | Optional CSS class for styling the component.                                            |
| spring               | SpringOptions | `{ mass: 0.1, stiffness: 150, damping: 12 }` | Spring options from motion for animation effects.                                        |
| magnification        | number        | 80                                           | The width of the item under the pointer, in pixels.                                      |
| distance             | number        | 150                                          | The distance from the center of a dock item at which the magnification animation starts. |
| panelHeight          | number        | 64                                           | The height of the panel at rest, in pixels.                                              |
| itemSize             | number        | 40                                           | The width of an item away from the pointer, in pixels.                                   |
| disableMagnification | boolean       | false                                        | Keeps every item at `itemSize`. Labels still appear.                                     |

### DockItem

| Prop      | Type       | Default   | Description                                                        |
| :-------- | :--------- | :-------- | :----------------------------------------------------------------- |
| children  | ReactNode  |           | DockLabel and DockIcon                                             |
| className | string     | undefined | Optional CSS class for styling the component.                      |
| href      | string     | undefined | Renders the item as a link to this address.                        |
| onClick   | () => void | undefined | Called when the item is clicked, or activated with Enter or Space. |

### DockLabel

| Prop      | Type      | Default   | Description                                                 |
| :-------- | :-------- | :-------- | :---------------------------------------------------------- |
| children  | ReactNode |           | Content of the label, typically a string or formatted text. |
| className | string    | undefined | Optional CSS class for styling the component.               |

### DockIcon

| Prop      | Type      | Default   | Description                                   |
| :-------- | :-------- | :-------- | :-------------------------------------------- |
| children  | ReactNode |           | Icon                                          |
| className | string    | undefined | Optional CSS class for styling the component. |

### DockSeparator

A vertical hairline between two groups of items.

| Prop      | Type   | Default   | Description                                                 |
| :-------- | :----- | :-------- | :---------------------------------------------------------- |
| className | string | undefined | Classes for the line, for example its height and alignment. |

## Accessibility

- The text of `DockLabel` names its item for screen readers even while the label is hidden, so every icon has a name.
- An item without `href` is a button: it takes focus, and Enter or Space activates it. Focus shows its label.
- The magnification follows the mouse only. With reduced motion, items resize without the spring.
