# Magic Card

A card that notices the pointer coming. As the pointer gets close, the stretch of border facing it lights up and turns to follow it around the card. Inside the card, a soft wash sits under the pointer.

The light belongs to one card and holds any content, buttons included. [Spotlight Cards](/docs/spotlight-cards) shares one light across a grid of link cards and lights only the edges near the pointer once it is over the grid; [Spotlight](/docs/spotlight) is a soft blob that follows the pointer inside any element.

## Component API

### MagicCard

Renders a `<div>` card with `rounded-xl`, the card background and a hairline. Every other `div` attribute passes through.

| Prop      | Type                   | Default   | Description                                                              |
| :-------- | :--------------------- | :-------- | :----------------------------------------------------------------------- |
| tint      | 'primary' \| 'neutral' | 'primary' | The colour of the light.                                                 |
| proximity | number                 | 120       | How far from the card, in px, the edge starts to light up.               |
| spread    | number                 | 70        | Half the width of the lit stretch of border, in degrees around the card. |
| className | string                 |           | Classes for the card, such as its padding.                               |
| children  | React.ReactNode        |           | The card content.                                                        |

## Accessibility and motion

- The light follows a mouse only. Touch and pen leave the card as it is.
- The card listens to the pointer only while it is on screen or close to it.
- The lit edge turns on a spring with no bounce and brightens as the pointer gets closer. The wash fades in over 300ms and out over 150ms.
- With reduced motion the edge sits exactly where the pointer is, with no spring. It still fades.
- The light layers are decorative and hidden from assistive technology.
