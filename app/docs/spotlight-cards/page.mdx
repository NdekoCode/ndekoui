## Component API

### SpotlightCards

The grid that tracks the mouse. Renders a `<div>` with `grid gap-3`; set the columns with `className`.

| Prop      | Type                   | Default   | Description                |
| :-------- | :--------------------- | :-------- | :------------------------- |
| tint      | 'primary' \| 'neutral' | 'primary' | The colour of the light.   |
| className | string                 |           | Classes for the grid.      |
| children  | React.ReactNode        |           | The `SpotlightCard` items. |

### SpotlightCard

A card that is a link. Renders an `<a>`: `href` and every other anchor attribute pass through. Its children stack in a column.

| Prop      | Type            | Default | Description           |
| :-------- | :-------------- | :------ | :-------------------- |
| className | string          |         | Classes for the card. |
| children  | React.ReactNode |         | The card content.     |

## Accessibility and motion

- The light follows a mouse only. Touch and pen leave the cards as they are.
- The light trails the pointer on a spring with no bounce. With reduced motion it sits exactly under the pointer, and it fades in and out the same way.
- The light layers are decorative and hidden from assistive technology.
