## Component API

### ScrollTextMarquee

| Prop          | Type                             | Default | Description                                                                                              |
| :------------ | :------------------------------- | :------ | :------------------------------------------------------------------------------------------------------- |
| children      | React.ReactNode                  |         | The line of text. Add a separator at its end to mark where one copy meets the next.                      |
| speed         | number                           | 60      | The speed at rest, in pixels per second. Scrolling at 1000 pixels per second makes it five times faster. |
| direction     | 'left' \| 'right'                | 'left'  | The direction at rest.                                                                                   |
| bidirectional | boolean                          | false   | Turns the row around while the page scrolls up.                                                          |
| repeat        | number                           | 4       | How many copies of the text fill the row. Raise it for short text on wide screens.                       |
| containerRef  | RefObject\<HTMLElement \| null\> |         | A scrolling element to follow instead of the page.                                                       |
| className     | string                           |         | Optional CSS class for the row. The default size is `text-5xl` and `sm:text-7xl`.                        |

The row only moves while it is on screen, and it stays still under reduced motion. The first copy is read by screen readers; the others are hidden from them.

Scroll pieces belong on marketing pages. A line that keeps moving needs a way to stop for people who find it distracting: reduced motion stops it here, and a page that relies on it can offer a pause control as well.
